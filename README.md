### 일하는 방식

CCTV 걷기/서기 판정을 처음 맡았을 때 참고할 선례가 없었습니다.
정지 영상으로 분류해보고, 탐지랑 분류를 한 모델로 합쳐보고, 세 번째에 프레임 간 이동량으로 갔습니다.
세 번 돌고 나서야 사진 한 장에는 걷는 중인지 서 있는 건지 구분할 정보가 애초에 없다는 걸 알았습니다.
그때부터는 모델을 키우는 것보다 문제를 다시 정의하는 게 빨랐고,
결국 전용 모델을 아예 지우고 기존 모델이 이미 뽑아둔 결과를 재사용했습니다. 성능이랑 GPU 부하가 같이 해결됐습니다.

점수가 잘 나오면 일단 의심하는 편입니다. 실제로 세 번 속았습니다.
검증 정확도 100%가 나왔을 때는 모델이 자세가 아니라 배경을 외운 거였고,
mAP 0.98짜리를 라이브에 올렸더니 재현율이 31%였습니다. 학습셋과 평가셋이 같은 영상에서 몇 초 간격으로 자른 거였거든요.
자체 평가 0.897도 배포 카메라에서 다시 재니 0.597이었습니다.

지표 고르는 것도 비슷합니다. 걷기가 74%인 데이터에서는 전부 걷기라고 찍어도 정확도 73.6%가 나옵니다.
그래서 균형 정확도로 봅니다.

배운 건 다음에 써먹습니다.
걷기/서기에 26일이 들었고 그중 절반 이상이 측정을 믿을 수 있게 만드는 데 들어갔는데,
그때 만든 학습 전략이랑 평가 하네스를 그대로 가져다 쓰니 다음 과제인 화분·방망이는 하루 만에 끝났습니다.
