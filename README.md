### 일하는 방식

모델을 만드는 것보다 **그 모델이 얼마나 잘 동작하는지 믿을 수 있게 만드는 데** 시간을 더 씁니다.
좋은 점수가 가짜였던 경우가 세 번 있었습니다.

- 검증 정확도 **100%** → 실제로는 자세가 아니라 **배경을 학습**하고 있었음
- 학습 mAP **0.98** → 라이브 재현율 **31%**. 학습셋과 평가셋이 같은 영상의 연속 프레임이었음
- 자체 평가 **0.897** → 배포 카메라에서 **0.597**. 평가셋이 학습 영상의 뒷부분이었음

세 번 다 "점수가 좋다"가 아니라 **"이 점수를 믿을 근거가 있나"**를 물어서 잡았습니다.
그 과정에서 만든 평가 하네스가 다음 과제의 26일을 **1일**로 줄였습니다.

지표도 같은 이유로 고릅니다 — 클래스가 74:26으로 기울어 있으면 **아무 판단도 안 하는 모델이 정확도에서 이깁니다.**
균형 정확도로 읽어야 75.5% 대 50.0%가 보입니다.
