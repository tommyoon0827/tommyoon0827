### 일하는 방식

**선례가 없으면 접근을 갈아엎습니다.**
CCTV 걷기/서기 판정은 참고할 선례가 없어서 세 번 방향을 바꿨습니다.
정지영상 분류 → 탐지·분류 통합 모델 → 이동량 기반.
세 번째에서야 **정지 영상 한 장에는 걷기와 서기를 구분할 정보가 원리적으로 없다**는 걸 확인했고,
그때부터는 모델을 더 키우는 대신 문제를 다시 정의하는 쪽이 빨랐습니다.
결국 전용 모델을 **제거하고** 기존 모델의 출력을 재사용해서, 성능과 GPU 부하를 동시에 해결했습니다.

**숫자가 좋을 때 한 번 더 의심합니다.**
좋은 점수가 가짜였던 적이 세 번 있었습니다.

- 검증 정확도 **100%** → 자세가 아니라 **배경**을 학습하고 있었음
- 학습 mAP **0.98** → 라이브 재현율 **31%**. 학습셋과 평가셋이 같은 영상의 연속 프레임이었음
- 자체 평가 **0.897** → 배포 카메라에서 **0.597**. 평가셋이 학습 영상의 뒷부분이었음

셋 다 "점수가 좋다"가 아니라 **"이 점수를 믿을 근거가 있나"**를 물어서 잡았습니다.
지표도 같은 이유로 고릅니다 — 클래스가 74:26으로 기울면 **아무 판단도 안 하는 모델이 정확도에서 이깁니다.**

**한 번 배운 건 다음 과제에서 회수합니다.**
걷기/서기에 26일이 들었고, 절반 이상이 "측정을 믿을 수 있는가"에 쓰였습니다.
그때 만든 학습 전략·평가 하네스·2차 모델 구조를 그대로 재사용해서
다음 과제인 화분·방망이 탐지는 **1일 만에** 끝냈습니다.
